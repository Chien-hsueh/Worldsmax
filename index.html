02Execute Monte Carlo Simulations

A full five-round Swiss run contains 33 match outcomes. If each match has two possible winners, that gives up to 233 (> 8.5 billion) possible match-outcome sequences, even before accounting for the different legal opponent draws.

The Swiss record-group and no-rematch rules constrain which pairings are allowed, but considering every possible result sequence and draw still creates a large search tree. Brute-force enumeration is impractical client-side in a browser.

Monte Carlo addresses this by repeatedly sampling tournament runs to estimate outcome frequencies. Estimates generally stabilize as the number of runs increases, but they remain estimates rather than exact probabilities.

03Qualification Probability Estimates

Review estimated qualification and elimination odds alongside 3-0, 3-1, and 3-2 score distributions. Estimates stabilize as the number of simulation runs increases.
